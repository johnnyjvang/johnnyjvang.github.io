A ROS 2 (Jazzy) mobile robotics project focused on TurtleBot3 navigation, autonomous exploration, multi-robot simulation, and camera-based robot following using ArUco markers.

Project Overview

This project was built as a hands-on testbed for learning and validating applied mobile robotics workflows using TurtleBot3, ROS 2, Nav2, Gazebo, and OpenCV.

The project combines autonomous navigation experiments with perception-based robot tracking. It includes timer-based patrol exploration, random safe goal exploration, two-robot Gazebo simulation, ArUco marker detection, marker pose tracking, and closed-loop robot-following behavior.

What Was Built

  • ROS 2 Python nodes for Nav2 goal navigation and exploration
  • Timer-based patrol exploration with saved map output
  • Random safe goal exploration for autonomous movement testing
  • Custom two-TurtleBot3 Gazebo simulation setup
  • ArUco marker detection using an RGB camera
  • ArUco pose tracking with robot-friendly coordinate conversion
  • Closed-loop follower node for visual robot following

Timer-Based Patrol Explorer

The timer-based patrol explorer sends Nav2 goals at timed intervals so the robot can patrol and explore a mapped environment.

Exploration Behavior

  • Dispatches navigation goals at timed intervals
  • Uses Nav2 to plan and execute paths
  • Tracks completed goal locations
  • Saves a map visualization of visited goals

ArUco-Based Robot Following

The ArUco following system demonstrates camera-based robot-to-robot tracking.

Perception to Control Pipeline

Camera → ArUco Detection → Pose Estimation → Pose Topic → Follower Controller → cmd_vel

Following Behavior

  • Moves forward when the target is far
  • Rotates toward the target when off-center
  • Stops at a defined distance threshold
  • Stops automatically if the marker is lost

Key Engineering Insights

  • Nav2 exploration benefits from structured goal generation
  • Camera frame differs from robot base frame
  • ArUco pose provides direct control signals
  • Perception and control should be modular

Future Improvements
