Hmonglish

Live Application: Hmonglish

An interactive vocabulary-learning web application built with HTML, CSS, and vanilla JavaScript to help users study foundational Hmong words through flashcards and simple study tools.

Project Overview

Hmonglish was built as a lightweight language-learning tool focused on helping users build confidence with beginner Hmong vocabulary in a simple, interactive format.

The application organizes words by category and provides a study flow that is easy to use on both desktop and mobile devices. Rather than focusing on complex features first, the project emphasizes usability, repetition, and accessible interaction.

The current version includes vocabulary categories such as animals, colors, and numbers, with flashcards implemented as the primary learning mode and additional modes planned for expansion.

What Was Built

  • Category-based homepage for vocabulary selection
  • Popup workflow for choosing between flashcard, quiz, and match modes
  • Interactive flashcard system with swipe navigation
  • Keyboard-friendly study controls for faster review
  • Shuffle feature to randomize flashcard order
  • Toggle between White Hmong and Green Hmong vocabulary/audio
  • Responsive layout for desktop and mobile use

Key Engineering Decisions

  • Built with vanilla JavaScript to keep the project lightweight and easy to deploy
  • Used Swiper.js for intuitive card navigation on both desktop and mobile
  • Added keyboard shortcuts to improve usability and support faster studying
  • Designed around simple category-based learning for clarity and accessibility
  • Structured the app to support future expansion into quiz and match-based modes

  • How to combine mouse, keyboard, and touch interactions into one interface
  • How to structure a vocabulary-learning application for future feature expansion
  • How small UI decisions can improve usability and learning experience
