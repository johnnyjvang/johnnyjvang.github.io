Eye Health Blink Detection

View Project on GitHub

A computer vision project built to track eye blinks in real time using a webcam, with the goal of monitoring blink frequency and encouraging healthier screen habits. I created this because I noticed my eyes often became red during long computer sessions and suspected that reduced blinking might be part of the cause.

Project Overview

This project uses facial landmark detection to identify the eyes, calculate the Eye Aspect Ratio (EAR), and determine when a blink occurs. The program works in real time using either a webcam or a video file.

In addition to detecting individual blinks, the system tracks blink frequency over time, logs blink counts in 20-second intervals, saves those results to CSV files, and shows a live plot for quick monitoring. The broader idea behind the project was to develop a tool that could eventually warn me when my blink rate becomes too low and suggest blinking more often or taking a break from the screen.

Problem Motivation

I wanted to explore whether computer vision could be used as a practical personal health monitoring tool. Since my eyes sometimes get red after extended computer use, I thought a useful first step would be to measure how often I blink during focused screen time.

The concept was simple: if the system can estimate the number of blinks per minute, then over time it could be used to identify periods of reduced blinking and provide reminders to blink more or rest the eyes. This made the project both a technical exercise in real-time vision and a practical experiment tied to everyday health habits.

How It Works

The program uses dlib's 68-point facial landmark detector to locate the eyes in each frame. From the eye landmarks, it calculates the Eye Aspect Ratio (EAR), which measures how open or closed the eye appears. When the EAR drops below a threshold for a short period, the event is counted as a blink.

The script continuously processes video frames, updates blink counts, records interval statistics, and visualizes blink activity over time.

Core Features

  • Real-time eye blink detection from a webcam
  • Support for prerecorded video input
  • Eye Aspect Ratio (EAR) calculation using facial landmarks
  • Blink counting over rolling 20-second intervals
  • Rolling average analysis for blink frequency trends
  • Automatic CSV export of blink interval data
  • Live blink frequency visualization with Matplotlib

System Pipeline

Webcam / video input
→ face detection
→ facial landmark detection
→ eye landmark extraction
→ Eye Aspect Ratio (EAR) calculation
→ blink event detection
→ interval logging and rolling averages
→ CSV output + live visualization

Installation

pip install dlib opencv-python numpy imutils scipy matplotlib seaborn

How to Run

Webcam input:

python3 blink_detection_final.py --shape-predictor shape_predictor_68_face_landmarks.dat --camera 0

Video file input:

python3 blink_detection_final.py --shape-predictor shape_predictor_68_face_landmarks.dat --video path_to_video.mp4

Program Output

  • A live detection window with blink status and EAR-based statistics
  • Blink counts recorded every 20 seconds
  • Rolling average trend visualization
  • Timestamped CSV files saved to /saved_csv

Why This Project Matters

This project shows how computer vision can be applied to more than robotics or object detection. It can also be used to measure small human behaviors in real time and turn them into useful feedback. In this case, the focus was on eye blink frequency as a possible indicator of screen-related eye strain.

It also demonstrates practical work in face landmark tracking, signal thresholding, time-series logging, visualization, and designing a system around a real personal use case instead of only a textbook example.
